# GameArknightUnity

A Unity tower-defense game project inspired by the gameplay style of **Arknights**.

## About the Project

GameArknightUnity is a personal Unity game development project focused on building a tactical tower-defense gameplay system.

The current gameplay concept includes:

* Enemy spawning and movement along predefined paths.
* Deployable Operators that can be placed on designated tiles.
* Different deployment areas for **Melee**, **Ranged**, and **Caster** Operators.
* Blue tiles representing enemy routes and Melee deployment positions.
* Path-based enemy movement toward the objective.
* A modular system designed to be expanded with more Operators, enemies, maps, and gameplay mechanics.

## Built With

* **Unity**
* **C#**
* Unity Prefabs & Components
* Custom path and spawning systems

## Project Status

**In Development**

Core gameplay systems are currently being implemented and tested. More mechanics, Operators, enemies, UI, and maps will be added as development continues.

## Main Systems

Some of the current systems include:

* `EnemySpawner` – Handles enemy spawning.
* `EnemyPath` – Defines enemy movement paths.
* Deployment tile system – Controls where different Operator types can be deployed.
* Enemy movement system – Moves enemies along their assigned paths.

## Goal

The goal of this project is to create a functional tactical tower-defense game while experimenting with Unity architecture, gameplay programming, and system design.
